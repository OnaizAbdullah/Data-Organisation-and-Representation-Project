# Data-Organisation-and-Representation-Project

• Make a folder called "templates" and put all the html files and image files inside that. Make sure the templates folder is in the same directory as the rest of the files.
• View various information (Average BMI Index, Self-Esteem etc...) through tables, a bar chart, a line chart and pie charts based on obesity.
• Engage with the website by adding in your own information and seeing it displayed.
